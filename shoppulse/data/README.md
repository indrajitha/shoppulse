# Data Directory

Place the Online Retail dataset here as `online_retail.xlsx` or `online_retail.csv`.

**Source**: UCI Machine Learning Repository / Kaggle  
- UCI: https://archive.ics.uci.edu/dataset/352/online+retail  
- Kaggle: https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci

The dataset contains ~540,000 real UK retail transactions from 2010-2011.

## Columns
| Column | Description |
|--------|-------------|
| InvoiceNo | Invoice number (C-prefix = cancellation) |
| StockCode | Product code |
| Description | Product name |
| Quantity | Units per transaction |
| InvoiceDate | Invoice date & time |
| UnitPrice | Price per unit (GBP) |
| CustomerID | Customer ID |
| Country | Country of customer |
